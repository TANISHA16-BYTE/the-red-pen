# The Red Pen — Brand Governance Platform

The Red Pen is a brand-governance project focused on reviewing content before publication.

It aims to help teams check content against approved brand guidelines, facts and assets before publishing.

## Live Demo
https://poetic-concha-796708.netlify.app

## Project Focus
- Brand consistency and approved terminology
- Content review before publishing
- Checking claims against approved information
- Identifying inconsistencies in campaign content
- Human review and approval workflow

## Tech Stack
- Next.js
- React
- TypeScript
- Supabase
- Tailwind CSS
